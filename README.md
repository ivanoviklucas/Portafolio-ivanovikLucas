## 📌 Sobre el Proyecto

Este es mi portfolio personal desarrollado con **React.js**, donde presento:

- 💼 Mis proyectos
- 🛠 Tecnologías que manejo
- 📄 Mi CV descargable
- 📬 Información de contacto

Fue creado a partir de una plantilla open source y completamente personalizado para representar mi perfil profesional como desarrollador web.
